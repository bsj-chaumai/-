QD xác nhận kết quả review

Reviewer ra 指摘数. QD nhìn quy mô + 指摘数 để quyết định đi tiếp hoặc yêu cầu verify lại.

Phân vai (vd PM)

RoleViệc
Spec ReviewerReview nội dung SPEC → đưa 指摘数
Spec QDXác nhận kết quả review SPEC
Ví dụ: SPEC 100 màn, 指摘数 = 1
→ QD: chất lượng review kém → yêu cầu verify lại SPEC (không tự review 100 màn).

QD cần thu thập

#Hạng mụcÝ nghĩa
1Quy môSố màn / chức năng / frame…
2Review đã xongAi + ngày + link
3指摘数Tổng số từ Reviewer
4Phân mứcCritical / High / Medium / Low
5Kết luận QDĐi tiếp / Verify lại
ĐỦ — review xong, tín hiệu hợp lý, High=0
VERIFY LẠI — review quá mỏng so với quy mô, hoặc High>0
