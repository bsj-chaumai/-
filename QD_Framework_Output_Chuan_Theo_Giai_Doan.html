QD Framework · Chỉ 3 giai đoạn

Output đánh giá cho QD

要件・計画 → 設計 SPEC → デザイン. QD check link + điều kiện → ĐỦ / CHƯA ĐỦ.

Cách đánh giá

OK — có link mở được + đúng cột “ĐỦ khi”
NG — thiếu link / link hỏng / sai điều kiện

Tất cả OK và Critical/High = 0 → ĐỦ. Một mục NG hoặc High > 0 → CHƯA ĐỦ → trả 担当.

1 · CHƯA ĐỦ → Dir / PM

設計 SPEC

#OutputĐỦ khi (QD check)

3Bảng nhánh / trạng tháiCó link hoặc mục rõ trong SPEC
4Review DevCó approve/comment của Dev
5Review QCCó approve/comment của QC
6Version / ngày khóaCó ghi version hoặc ngày khóa
7Critical / HighCòn mở = 0
