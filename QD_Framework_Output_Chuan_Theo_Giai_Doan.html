QD Framework · Bộ output chuẩn

Đánh giá chất lượng: 要件・計画 / 設計書・SPEC / デザイン

QD check độ phủ cấu trúc (Có/Không) + độ tin cậy review (quy mô ↔ 指摘数) → PASS / REWORK / VERIFY.

Cách đánh giá

PASS
Đủ độ phủ + review đáng tin + High=0 → đi tiếp
REWORK
Còn Critical/High mở → đóng 指摘 rồi check lại
VERIFY
Thiếu hạng mục cấu trúc hoặc review quá mỏng (vd. 100 màn/1 指摘)

1) Reviewer = đúng/sai nội dung → 指摘数.
2) QD = độ phủ Có/Không + quy mô↔指摘数 → PASS / REWORK / VERIFY.
